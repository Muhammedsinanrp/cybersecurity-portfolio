## 🌟 Features & Highlights

- **🌌 3D WebGL Cyber Core & Particle Field**: Built with Three.js featuring interactive mouse physics, parallax, and orbital data packets.
- **🛸 3D WebGL Technical Arsenal Galaxy**: Interactive 3D spherical node graph of core security tools (Splunk, Microsoft Sentinel, Wireshark, Nessus, Defender for Endpoint, VirusTotal, Kali Linux, Python, etc.) with click-to-focus raycasting.
- **🔬 3D Holographic Tool Inspector & Live Simulator**: Interactive execution simulations for Splunk queries, KQL scripts, Wireshark PCAPs, and Python automation.
- **💻 Interactive Hacker CLI Terminal**: Fully functional terminal console supporting `help`, `whoami`, `skills`, `experience`, `projects`, `certs`, `scan`, `matrix`, `theme`, and `clear`.
- **📡 Live SOC Threat Radar & SIEM Telemetry HUD**: 360° animated radar sweep with real-time incident event log feeds.
- **🔊 Web Audio API Synthesizer**: Pure client-side sci-fi sound effects and audio telemetry (zero external audio file dependencies).
- **🎴 3D Holographic Card Matrix**: Multi-layer perspective tilt cards with sweeping 3D laser scanlines.
- **🔒 Encrypted Contact Dispatch Station**: Secure message dispatch simulator and 1-click email copy.

## 🛠️ Tech Stack

- **Core**: HTML5 Semantic Architecture, Modular JavaScript (ES6+)
- **Styling**: Vanilla CSS3, Custom Cyber Design Tokens, Glassmorphism, 3D Perspective Matrix
- **3D Graphics**: [Three.js](https://threejs.org/) (WebGL)
- **Audio FX**: Web Audio API Synthesizer
- **Icons & Fonts**: FontAwesome 6, Google Fonts (Orbitron, JetBrains Mono, Inter)
